# 08 · Lưu trữ core phân tích cũ

Thư mục này giữ bản `j04_display_core` và testbench tương ứng để có thể đối chiếu
với phần phân tích ban đầu. Đây **không** phải bản gốc của top TinyTapeout do giảng
viên cung cấp, cũng không phải RTL của run GDS hiện tại.

Nguồn top TinyTapeout được giữ tại `src/project.v` và bản mô phỏng/flow tại
`rtl/project.sv`; hai file hiện giống hệt nhau. Core trong thư mục này có giao diện
khác và không được dùng thay cho các file đó.
